### 3.2 首页「品牌代理&经销」15 宫格严重变形、模糊且品牌不全

## 四、P1 搜索框、产品库与表单交互功能 BUG 审计

### 4.1 连接器型号搜索框存在严重前后端断层与产品页失灵 BUG
1. **产品展示页（`tid=3`）搜索下拉框 100% 废死**：
   - 首页顶栏在 HTML 中硬编码输出了全部 383 个 `<div class="lp-datalist-item">`（导致首页 HTML 膨胀）；
   - 但在用户最需要搜索的 **产品展示页（`tid=3`）及搜索结果页**，模板漏写了循环输出型号项的代码，`#lp-datalist` 内仅有 `<div class="lp-datalist-noitem">没有找到该型号</div>`。用户在产品页输入框敲入**任何**真实存在的型号（如 `368500`），前端 JS 遍历 0 个节点后立即强制弹出 **“没有找到该型号”**！
2. **后端检索接口不支持模糊查询（差一个字符即返回 0 结果）**：
   - 前端 JS 下拉匹配时剥离了连字符 `-` 做模糊包含判断，但用户按回车或点搜索按钮触发 `/?m=home&c=Lists&a=get_product_data&tid=3&connector_model=...` 时，后端 SQL 执行严格精确等于匹配：
     - 实测请求 `connector_model=368500-1` → 返回 1 条结果；
     - 实测请求 `connector_model=368500`（仅少 `-1`）→ **返回 0 条结果**！
   - 此外，数据库内部分型号末尾带有脏空格（如 `id=383` 的 `'PPI0000453 '`），极易造成精确检索失败。
3. **搜索按钮视觉隐形与冗余代码**：
   - 首页顶栏放大镜图标 `.lp-icon-search` 纯靠 CSS `border` 与 `:after` 伪元素拼凑，默认颜色设为 `#ebebeb`（极浅灰，白底下几乎看不见），且无 `<button>` 无障碍语义；
   - 内页 HTML 中还残留了一整套隐藏未用的旧版 `.searchBar-m` 弹窗搜索表单和会员登录弹窗（每次加载页面还额外触发两次 `/?m=api&c=Ajax&a=vertify&type=users_login` 验证码图片请求，拖慢首屏）。

1. **PC 端完全缺失 Viewport 声明**：全站 PC HTML `<head>` 均未声明 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`，在小屏或平板横屏下页面缩成极小比例或产生严重横向滚动。
2. **手机访问触发 EyouCMS 演示模板事故**：使用 iPhone / Android 移动端 UA 请求首页时，后端返回一套仅 `7,898 bytes` 的独立移动端模板：
   - 轮播图变成 **3 张 `update.eyoucms.com/demo/...` 2019 年官方演示图**；
   - 首页“产品推荐”为空，“公司简介”仅显示 `...`；
   - **彻底丢失了汽车连接器型号搜索框与 17 大合作品牌展示**；
   - 底部固定栏显示“首页 / 产品 / **方案** / **动态**”，点击“方案”直接进入蓝牙耳机渲染与手机摄影假页面！

### 5.3 服务端安全、性能与合规隐患
1. **无 HTTPS 加密**：全站仅跑在 `http://` 80 端口，现代浏览器地址栏直接标记“不安全”，在线留言与客户手机号明文传输。
2. **远古 EOL 软件栈与极低并发承受力**：响应头暴露 `Server: nginx/1.12.1`、`X-Powered-By: PHP/5.4.16`（PHP 5.4 已于 2015 年停止官方安全支持）；实测并发请求达到 6~10 个时，后端频繁崩溃返回 **`502 Bad Gateway`**。
3. **版权年份停滞与备案号缺失**：页脚写死 `2012-2022`，未体现最新经营状态，且缺失工信部 ICP 备案号展示。
